React18的新特性

发表于 2024-03-25

React 18 是 2022 年发布的版本，引入并发渲染（Concurrent Rendering） —— 允许 React 中断、暂停、恢复或放弃渲染，避免渲染阻塞主线程（如输入、滚动），同时大幅提升性能和开发体验。以下是核心特性（按重要性排序）：

1. 并发渲染（Concurrent Rendering）

这是 React 18 最核心的变化：

  • 作用：传统渲染是同步且不可中断的（一旦开始渲染，必须完成，否则阻塞用户交互）；并发渲染允许 React “在后台” 渲染组件，不阻塞主线程，用户操作（如输入、滚动）更流畅。
  • 启用方式：通过 createRoot 替代旧的 ReactDOM.render。

2. 自动批处理（Automatic Batching）：减少不必要的重渲染

  • 作用：React 会自动合并多个 setState 更新，只触发一次重渲染（之前仅在事件处理函数中批处理，异步代码/定时器中不生效）。
  • 解决的问题：避免多次 setState 导致的重复渲染，提升性能。

3. Transitions API：区分「紧急/非紧急更新」

  • 作用：将更新分为紧急更新（如输入框打字、按钮点击）和非紧急更新（如列表筛选、大数据渲染），避免非紧急更新阻塞紧急操作。
  • 核心 API：useTransition（Hook）、startTransition（方法）。

4. Suspense 增强：支持数据请求 + 流式渲染

  • 作用：React 18 扩展了 Suspense 的能力，从代码分割扩展到数据请求（配合 React Server Components），支持“加载中占位 + 流式渲染”。
  • 核心场景：等待数据加载时显示兜底 UI，数据加载完成后渲染组件，无需手动处理 loading 状态。

5. 其他实用特性

  • useDeferredValue：延迟更新非紧急值（类似防抖，但由 React 控制时机），适合大数据渲染；
  • useId：生成跨服务端/客户端的唯一 ID，解决 SSR 时 hydration 不匹配的问题；
  • hydrateRoot：替代旧的 hydrate，支持并发模式下的 SSR 水合。

浏览器输入url会发生什么

发表于 2024-04-17
  1. dns解析获取IP地址
    1. 查找缓存，浏览器缓存，操作系统缓存，路由器缓存，ISP缓存
    2. 缓存没找到的话，通过递归的方式去dns服务器查找，根域名服务器，顶级域名服务器，权威域名服务器
    3. 找到ip地址后，可以通过该ip地址连接服务器，并且ip地址信息会被发送回用户的电脑，缓存下来
  2. 建立TCP链接，三次握手
  3. 发送http请求，获取到index.html
    1. 创建DOM tree
    2. 遇到link标签，下载css文件，创建cssOM
    3. 将css attachment到DOM tree 形成render tree
    4. 浏览器进行layout和paint
  4. 回流和重绘
    1. 回流reflow, 第一次计算大小和位置的时候是layout, 之后再次计算大小和位置是回流
      1. 什么时候会回流?
        1. dom结构发生了改变
        2. 改变布局，例如width height padding font-size
        3. 窗口resize
        4. 调用getComputedStyle方法获取尺寸和位置信息
    2. 重绘repaint，第一次渲染内容为paint, 之后重新渲染称为重绘
    3. 回流一定会引起重绘，消耗性能，怎么避免回流
      1. 尽量一次性修改css
      2. 避免频繁操作DOM
      3. 避免调用getComputedStyle方法获取尺寸和位置信息
      4. position 为absolute和fixed开销相对较小
  5. 新的合成层CompositingLayer
    1. 将元素绘制到多个合成图层中
    2. 通过一些方法创建新的合成图层, 新的图层可以利用GPU来加速绘制
      1. 3dtransforms/video/canvas/iframe/position:fixed/will-change
      2. 但是以内存管理为代价，不能滥用
